# 术语表（续费率下降分析）

> 本例数字均为虚构。
> 用法：给增长和产品负责人看的报告只用“统一写法”这一列的词；首次出现时按“含义”就地解释。要用表里没有的专业词，先补进这张表。
> 标着“待确认”的，是现有记录里没有写清的，不要自己补定义。

| 统一写法 | 含义（首次出现时这样解释） | 不要写成 |
|---|---|---|
| 续费率 | 当周到期的订阅里，在到期后 3 天内续费成功的比例 | 续订率、留存率 |
| 主动取消 | 到期前用户自己关掉了自动续费 | 主动退订、流失 |
| 扣款失败 | 自动续费开着，但到期时没扣成（卡过期、余额不足等） | 被动流失 |
| 首次续费 | 一个订阅第一次到期时的续费；之后的叫多次续费 | 新客续费 |
| 宽限期 | 到期后还算“按时续费”的 3 天；待确认：应用商店渠道是否也是 3 天 | 缓冲期 |
| 构成变化 | 到期订阅里各类订阅的比例变了，即使每一类的续费率都没变，整体续费率也会跟着变 | 结构性因素 |
