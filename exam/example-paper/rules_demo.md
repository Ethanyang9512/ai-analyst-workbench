# 示例写作规则（考场演示用，虚构）

> 这是给 exam/example-paper 演示用的一小份规则，模拟“写作技能 + 台账”里的条目。真实使用时，rules.json 指向你自己的技能和台账文件。

1. 第一部分只写结论，不写分析过程；“本次分析首先……然后……”这类过程叙述整段删掉。
2. 加粗的结论句不超过 40 字；长句拆成“一句加粗的结论 + 一段不加粗的解释”。
3. “值得注意的是”整句删，或改成直接陈述。
4. 不用“断崖式”“暴跌”这类渲染词，写“下降”。
5. 百分比和 pt 保留一位小数。
6. 一个概念全文一个叫法：写“续费”，不写“续订”。
7. 不写“我们认为”“我们判断”，写“数据显示”。
8. 给业务看的稿子不写内部包号和取数过程，不写“仅供参考”“可能存在偏差”这类自我削弱的话。
