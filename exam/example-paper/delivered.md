# 续费率下降分析（W1–W8）

> 本例为虚构示例：产品、方案和全部数字均为虚构。

## 一、分析过程与结论

本次分析首先从到期订阅明细出发，按周计算了续费率，然后把未续费的订阅拆成主动取消和扣款失败两类，最后按方案和续费次数下钻。

**结论：续费率从 W5 的 80.8% 断崖式下跌到 W6 的 76.98%，比 W5 低 3.78pt，我们认为主要原因是去年首年优惠买的年付订阅从 W6 起集中迎来第一次续费，同时月付方案 W6 起涨价，扣款失败基本没有变化，W7、W8 续费率维持在低位。**

值得注意的是，续费率的分母是当周到期的订阅数，不是当周活跃订阅数。

## 二、续费率的周走势

| 周 | 到期订阅数 | 续费率 |
|---|---|---|
| W1 | 1.78万 | 80.7% |
| W2 | 1.81万 | 80.8% |
| W3 | 1.79万 | 80.8% |
| W4 | 1.81万 | 80.6% |
| W5 | 1.80万 | 80.8% |
| W6 | 2.00万 | 76.98% |
| W7 | 2.04万 | 76.7% |
| W8 | 1.98万 | 77.2% |

W6 之前续费率稳定在 80.6%–80.8% 之间，W6 起掉到 77% 左右，之后两周没有回升。

## 三、未续订的两类

- 主动取消占到期订阅的比例：W5 14.3%，W6 17.7%，上升 3.4pt。
- 扣款失败占到期订阅的比例：W5 5.0%，W6 5.3%，基本没变。

主动取消上升 3.4pt，解释了续费率下降 3.78pt 里的大部分。

## 四、到期订阅的构成变化

- 首次续费占到期订阅的比例：W5 21.1%，W6 29.0%。
- 多出来的首次续费几乎都是年付：年付首次续费的占比从 4.4% 升到 14.0%，这类订阅的续费率 W6 是 57.0%，和 W5 持平。
- 构成变化单独拉低续费率 2.3pt。

## 五、月付涨价的影响

月付多次续费的续费率从 84.0% 降到 82.0%，月付首次续费从 70.0% 降到 68.0%，其中多为对价格敏感的学生用户；年付没有涨价，多次续费的续费率保持在 86.0%。各类续费率的变化合计拉低 1.5pt，全部来自月付。

## 六、待确认事项

- W6 是否还有别的只影响月付的变化，需要业务确认。
- 以上数据来自取数助手第 1 轮回包，结论仅供参考，可能存在一定偏差。
