# 记忆索引的写法

`MEMORY.md` 是 Claude Code 每个会话自动加载的记忆索引。它有长度上限，所以只放**一行一条的指针**，细节放在它指向的文件里（同一个 `memory/` 目录下）。

- 一行一条：短横线开头，方括号里写标题、圆括号里写文件名做成链接，破折号后面一句话说明（照同目录 `MEMORY.md` 的样子）。
- 记忆放**偏好和指针**：用户的长期偏好、去哪里找口径、哪个项目在哪个工作区。业务口径本身放知识库，做法放技能，项目事实放项目的 `_status.md`。
- 每次会话都该先读的那几条，开头标 ★。
- 过时的条目删掉或改掉，不并列新旧两条。
- 工作群里不主动提个人类记忆；只有用户明确说“适用于所有项目”的偏好才写进共享记忆。

同目录的 `MEMORY.md` 是三条虚构指针的样例，它指向的三个文件也在这里，演示一条记忆文件长什么样。
