## 程序检查用（deckcheck.py 读这一段）

```json
{
  "banned": [
    {"word": "值得注意的是", "use": "", "why": "用户纠正过两次（示例）"}
  ],
  "display_names": {
    "voluntary_cancel": "主动取消"
  },
  "codes": {
    "甲店": "1001"
  },
  "terms": ["续费率"],
  "variants": {"续费率": ["续订率"]},
  "allow": ["首次续费率"]
}
```

<!--
json 各键的意思（deckcheck.py 的 CONV_KEYS）：
- banned：禁用词。word 是不能出现的写法，use 是该用什么（可以为空，表示直接删），why 写出处。
- display_names：对象的统一显示名。左边是常见写法，右边是页面上要用的写法（例如系统字段名换成读者认识的中文名）。
- codes：对象名 → 编号（一个或多个），门店、站点、渠道都能用。设了才检查“对象名前带编号”；项目不需要这条规矩就删掉这个键。
- terms：本项目的正式术语，检查时整词保护，不拆开报错。
- variants：正式术语 → 不该出现的变体写法。
- allow：放行的长词（里面含约定词但整体是另一个意思，例如“首次续费率”里含“续费率”）。
上面 json 里的每一条都是虚构示例，换成你自己的。没有要查的键可以删掉，但至少留一个键，否则 deckcheck 认不出这是约定页。
-->
