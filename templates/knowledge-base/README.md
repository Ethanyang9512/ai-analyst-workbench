# 知识库模板

知识库放**可复用的业务口径和来源**：指标怎么算、表怎么连、哪天发生过什么事、做过哪些项目和结论。分析助手和你在任何项目里都能查到它，换项目也不用重讲一遍。把这个目录复制到 `$AAW_KB`（默认 `~/aaw-kb`），按模板往里填你自己的内容。

## 放什么、不放什么

| 放在哪 | 放什么 | 为什么放这里 |
|---|---|---|
| 知识库（本目录） | 口径、指标卡、业务事件、项目索引——跨项目都要用、变得慢、要有出处的事实 | 谁都能查，一处改处处生效 |
| 记忆（`~/.claude/projects/*/memory/`） | 用户的偏好和指向知识库的指针 | 每个会话自动加载，但有长度上限，只放短的 |
| 技能（`~/.claude/skills/`） | 做法：怎么写报告、怎么审数据包、怎么出图 | 按需加载，规则和流程放这里 |
| 项目工作区 | 审核证据、版本历史、交付物、项目自己的约定页 | 只和这个项目有关，项目结束后选一部分回流到知识库 |

## 目录

| 文件 | 管什么 |
|---|---|
| [项目索引.md](项目索引.md) | 做过的工作项目一行一个：要回答的问题、方法要点、关键结论（有出处才写）、成品位置、踩过的口径坑 |
| [业务事件日历.md](业务事件日历.md) | 带日期的业务事件（促销、调价、版本上线、系统切换、节假日、口径变更）。解释指标波动前先查这里 |
| [指标卡/_模板.md](指标卡/_模板.md) | 一个指标一张卡：定义、分子分母、最近的数、数据从哪来、常见的坑、怎么跟领导解释 |
| [口径文档_模板.md](口径文档_模板.md) | 一件口径的事一个文件，文件名带日期，开头写依据和适用范围 |
| [项目收尾清单.md](项目收尾清单.md) | 项目结束时整理的八项，决定哪些回流到知识库 |

分析可复核性的总规矩（SQL 分步带版本、Excel 留公式、图可重画）在技能 `skills/reproducible-analysis/`，这里不再放一份。

## 什么时候写回

1. **用户说“记住”**＝落盘到知识库（并在记忆里留一条指针），不是只放在上下文里。
2. **同类纠正第二次出现**，先写进项目的 `_CONVENTIONS.md`；跨项目都适用的，项目结束时再回流到知识库。
3. **项目结束先问用户再回流**，三步：项目约定页里通用的条目 → 知识库对应的口径文档或指标卡；项目索引补一行；业务事件日历补上项目里查清的事件。
4. **重写或压缩之后回原稿核对两样**：数字和限定语（“约”“以上”“仅限月付”这类词最容易在压缩时丢掉）。

## 三条通用规矩

- **查不到写“—”或“待确认”，不要自己补。**
- **每条写出处**（哪个文件、哪次会议、谁说的），不写出处的事实下次没人敢用。
- **数字写适用范围**（哪几周、哪个对象、哪个口径），离开范围的数只能当参照。
