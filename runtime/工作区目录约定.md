# 工作区目录约定

一个飞书群对应一个项目，一个项目对应一个工作区目录。分析助手在群里干活时，当前目录就是这个工作区；它读写的所有项目文件都在这里，换群就换目录，项目之间不串。

## 总目录长什么样

```
$AAW_WS_BASE/                 默认 ~/aaw-workspaces
├── default/                     私聊用的基础工作区
│   ├── CLAUDE.md                共享手册（runtime/manual/CLAUDE.md 的副本）
│   └── .claude/settings.json    基础设置；newproject 开新区时先复制它
└── renewal-analysis/            一个项目工作区（一个群）
    ├── CLAUDE.md                群名、chatId、@../default/CLAUDE.md、本项目约定
    ├── .claude/settings.json    由 workspace_settings.py 维护（钩子、推理强度、写入门槛）
    ├── bin -> runtime/bin       进度卡等小脚本（软链）
    ├── _status.md               现状摘要 + 历史记录
    ├── _CONVENTIONS.md          口径与用词约定（含给程序读的 json 块）
    ├── _glossary.md             术语表
    ├── _acceptance/records.jsonl  验收记录（accept_record.py 写，gate.py 读）
    ├── _doc_assets/             发布过的飞书文档正文快照，应对“看我改了哪里”
    ├── brief.md                 开题的五要素 brief
    ├── 取数字段清单.md          给取数助手的第一份清单，之后的需求包都带上它
    ├── 需求包_v1.md …           给取数助手的需求包，一次一个文件
    ├── round1/ round2/ …        审核一轮一个目录：数据包解在这里，审核报告也放这里
    ├── sql/                     分步 SQL（S01_…_v1.sql）和 _CHANGELOG.md
    └── 报告_v1.md、汇报_v2.pptx …  交付物，版本化命名，不覆盖旧版
```

## 约定文件各管什么

| 文件 | 管什么 | 谁写 | 什么时候读 |
|---|---|---|---|
| `CLAUDE.md` | 这个群是谁、群号、导入共享手册、本项目的固定做法 | `newproject` 生成，用户或分析助手补 | 每个会话自动加载 |
| `_status.md` | 顶部「现状摘要」块按固定顺序写：当前在做、下一步、仍然有效的限制、最近的决定、在等谁、当前有效成品和链接、给取数助手的交接。不超过 5,000 字，写“更新于”时间。下面是历史记录 | 分析助手，每轮有实质进展就更新 | 新会话首轮由 `status_preview.py` 附带预览；之后按需分段读 |
| `_CONVENTIONS.md` | 用户纠正过两次的口径和用词：讲给谁讲什么、口径、页面上不出现的、写法；最后一段 json 给 `deckcheck.py` 读 | 分析助手（同类纠正第二次时写），用户可改 | 做页面前对照；图表数字验收员每次都拿到它 |
| `_glossary.md` | 统一写法、首次出现怎么解释、不要写成什么 | 分析助手起草，用户过目 | 写给业务看的稿子时；读者验收员拿到它 |
| `_acceptance/records.jsonl` | 每次验收一行：文件指纹、档位、页、两位验收员的结论 | `tools/accept_record.py` | 验收门在发送前读；`status` 判断该不该全稿通读 |
| `_doc_assets/` | 飞书文档每次发布后的正文快照 | 分析助手 | 用户问“我改了哪里”时比对 |

模板在仓库 `templates/workspace/`，一个完整的虚构项目在 `examples/续费率下滑归因/`。

## 几条容易踩的

- **建了目录不等于群已路由过去**：要用户在群里自己发一次 `/cd <绝对路径>`（机器人发的不算命令）。
- **新目录缺设置会静默失败**：如果你的网络要代理，代理写在工作区 `.claude/settings.json` 的 `env` 里；新目录没有这份设置会 403 且不报错。`newproject` 会先复制 default 的设置。
- **记忆按路径挂载**：Claude Code 按工作区路径给记忆找位置，换了路径记忆就“散架”。想各群共用一份，开区前设 `AAW_SHARED_MEMORY`。
- **目录名只用英文、数字和 -**：会话和记忆目录名按路径换算，中文和空格都会变成 -，容易撞名。
- **交付物不覆盖**：`报告_v2.md` 不覆盖 `报告_v1.md`；审核一轮一个目录，不覆盖上一轮。被否定的版本留着，但不能再称“认可”。
