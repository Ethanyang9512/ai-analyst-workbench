# 分析类汇报（readout）的写法

> `pyramid-storyline` 的参考文件。示例均为虚构。这些写法在数据分析、实验评估的公开教材和行业实践里常见，这里整理成可以直接照做的规则。

| 规则 | 例 |
|---|---|
| **一句话主旨**：整份材料压成一句完整的话，含观点、利害和要对方做的事 | “续费率下降可以解释：60% 是首次续费变多，40% 是月付涨价；建议 W10 复看涨价的影响” |
| **三分钟版本**：先写“只给你三分钟怎么讲”，再压成一句 | 背景 → 做了什么 → 结果 → 要你做什么 |
| **摘要和正文一一对应**：摘要每一条＝正文一章的首句；每章的全部内容只撑这一个点 | 摘要第 2 条“月付涨价拉低 1.5pt” ↔ 第五章首句 |
| **是什么 / 所以呢 / 接下来**：数据 → 用参照系翻译出含义 → 行动或“先观察” | “年付首次续费的续费率 58.0%（是什么），比多次续费低约 25pt（所以呢），建议首年优惠到期前加一轮提醒（接下来）” |
| **洞察要带为什么**：只有数是观察；带着比较对象和原因才是洞察 | “退款率 8%”是观察；“8%，是同类方案的 2 倍，集中在两个价格档”是洞察 |
| **实验读数的固定结构**：结果（时间、指标、区间、决定）→ 次要发现 → 下一步 → 附录（方法） | 本工作台的报告第一章＝结论与建议，判定方法放各章末和口径说明 |
| **实验决定分四档**：区间下界高于阈值 → 采用；上界低于 0 → 拒绝；区间全在可忽略带内 → 维持现状；区间远宽于可忽略带 → 继续收集 | 见仓库里的第二个示例“新手引导改版评估” |
| **不显著不等于没效果**：写“未观察到可识别的差异（区间 −X 到 +Y）”；要说“可以忽略”，阈值必须事先定好 | “改版组的激活率高 0.4pt，区间 −0.8pt 到 +1.6pt，跨过了 0” |
| **剔除要计数**：每一层过滤写出剔了多少；比率写清分子分母 | “剔除测试账号和赠送订阅后剩 19,800 个” |
| **周会只讨论能控制的指标**：正常波动一句“无异常”；异常要么给原因，要么写“在查，某日前回复” | — |
| **建议写清三样**：动作、谁来做、什么时候；不写“需进一步研究” | 待决定事项表每条写“由增长组落地，W10 前完成” |
| **摘要不超过一页**：问题 → 方法一句 → 发现 → 建议；不写“显著”“大幅”这类空词，给数字 | — |
