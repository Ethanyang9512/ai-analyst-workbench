# 五要素 brief 模板

> 复制下面的骨架，填完发给 Claude。写不全也没关系，缺的项 Claude 会一次问齐。

```
1. 背景
   - 业务场景是什么？涉及哪些团队？
   - 这个分析或模型的结果拿去做什么决定？
   - 附上相关材料：Excel、SQL、截图、以前的代码

2. 要回答的问题
   - 测算 / 建模 / 口径核对 / 解释波动 / 方案设计？

3. 交付形式
   - Excel（几个子表）/ 说明文档 / 报告 / 汇报片 / 加了注释的代码
   - 给谁看：自己 / 业务同事 / 管理层

4. 限制
   - 哪些数据现在没有？
   - 哪些地方不许假设，哪些可以先粗设参数？

5. 检查点
   - 哪些点要我拍板？不清楚的先讨论，不要凭空编。
```

## 一个填好的例子（虚构，数字均为编的）

- 背景：示例 App 的周续费率 W6 起比前 5 周低约 4pt，增长负责人要在周会上解释原因；附 W1–W8 的周报截图和取数助手交来的到期订阅明细。
- 要回答的问题：续费率下降是主动取消还是扣款失败变多；集中在哪类订阅；和同期的月付涨价有没有关系。
- 交付形式：一份飞书报告（结论先行，配图）加一个 Excel 图表包（每张图一个子表，公式保留）。
- 限制：渠道字段只有 W3 起才有，W1–W2 不能按渠道比；“月付涨价”的影响只能对齐时间点，不能直接写成原因。
- 检查点：续费率的分母用当周到期订阅数还是当周活跃订阅数；“首次续费”怎么定义（按付费周期序号还是按购买日期），需要我拍板。
