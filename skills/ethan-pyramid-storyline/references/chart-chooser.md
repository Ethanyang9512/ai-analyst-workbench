# 选图：想说什么，用什么图

> `ethan-pyramid-storyline` 的参考文件。这里只管选图型和叙事手法；画法、配色和出图后自检以 `ethan-report-writing/references/chart-style-guide.md` 为准。思路来自 Gene Zelazny《Say It With Charts》的五类比较、Cole Nussbaumer Knaflic《Storytelling with Data》、Stephen Few 的仪表盘与图表设计著作、Andrew Abela 的 Chart Chooser，以及 IBCS 国际商务沟通标准。

## 一、对照表

| 想说什么 | 用什么图 | 要点 |
|---|---|---|
| 谁高谁低、排名 | 横向条形图；项目超过 12 个用点图 | 按值排序；重点对象黑，其余灰 |
| 随时间怎么变 | 期数少用柱，期数多用线 | 时间一律放横轴；相邻几张线图刻度一致 |
| 各部分占总量多少 | 100% 堆叠条，或很简单的饼图 | 不超过 5 段，“其他”放最后用灰；只关心比例用 100%，比例和总量都要看用普通堆叠 |
| 从 A 走到 B 由哪些部分构成 | 瀑布图 | 只画能累加的分解；互斥的情景用横条，不用瀑布；柱子不超过 10 根 |
| 前后对比、重点是“变了多少” | 配对柱 + 差值标注；项目多时用箭头图 | 差值标注用深灰底白字，不用绿红 |
| 起点不同的几条线，比增速 | 指数化折线（基期 = 1.0） | 基期写进副标题 |
| 实际、应有、上限放一起 | 双柱 + 一段红色上限线 | 判定文字放柱下 |
| 实际是否落在正常范围 | 灰色正常带 + 实际线 | 写明灰带是什么范围（历史 80% 的读数、±2 倍标准差）；给出完整历史，别把正常波动画成危机 |
| 某件事之后趋势变了没有 | 折线 + 竖虚线标事件 | 竖线必须带文字（“W6 月付涨价”）；虚线＝参考或预测，实线＝实际 |
| 很多条线缠在一起 | 小多图（每个对象一个小面板） | 所有面板同轴同刻度 |
| 两组走势差多少 | 两条线 + 差值括号 | 让标注替读者做减法 |
| 排名怎么变 | 斜率图（两三个时点）；超过 15 项用排名表加变化列 | 不用 bump chart 和哑铃图 |
| 矩阵里的高低模式 | 单色热力图 | 行列按值排序；看出结论后改成更直接的图 |
| 很多类别 × 一个指标 | 表格 + 数据条（渲染成图） | 隔行浅灰；有正负时用零点竖线 |
| 实际、计划、预测同图 | 实心 / 空心描边 / 斜纹区分 | 单色体系下用纹理区分，不加颜色 |

## 二、叙事手法

1. **图是一句话**：标题单独拿出来也能懂；“趋势”“现状”这类标题算失败。
2. **只用一处强调**：灰底上一处高亮指向结论；不要粗体、颜色、大小三种强调一起上。
3. **只放打磨过的一两张主图**：探索时画的全量图不进汇报。
4. **标注分两种**：说“是什么”的、说“为什么”的；一张图一两个就够。
5. **差值替读者算好**：两条线之间用括号写差值，两根柱之间用差值标注。
6. **“什么是正常”画成灰带**：本期落在带里，就说“在日常波动范围内”，这是讲“没有变化”最诚实的画法。
7. **预测带不确定性**：中值实线加灰色区间；区间的数写在正文。
8. **诚实地画“没测出变化”**：画处理组减对照组的差值点和区间，以 0 为参考线；区间跨过 0＝分辨不出。同时给幅度和区间，不只说“显著 / 不显著”。
9. **前后对比先看前期是否平行**：对照组和处理组同轴两条线，前期平行，后期的差才有意义。
10. **刻度诚实**：柱图从 0 起；线图可以不从 0 起，但相邻几张图的范围一致，不压缩刻度把小波动画成剧变。
