# 选图：想说什么，用什么图

> `ethan-pyramid-storyline` 的参考文件。这里只管选图型和叙事手法；画法、配色和出图后自检以 `ethan-report-writing/references/chart-style-guide.md` 为准。思路来自 Gene Zelazny《Say It With Charts》的五类比较、Cole Nussbaumer Knaflic《Storytelling with Data》、Stephen Few 的仪表盘与图表设计著作、Andrew Abela 的 Chart Chooser、IBCS 国际商务沟通标准，以及咨询公司公开发布的报告和汇报片里常见的标注方式。

## 零、动手前先想两三种画法

别默认柱图和折线。先说清这张图要讲的是哪一类话，在下面的对照表里找两三种能讲这句话的形式，挑最形象、文字最少的那一种；拿不准时，用同一组数据各画一张小图比一比。

- **留下想过的痕迹**：故事线清单里，每张主图写明用哪种形式（用下表里的名字），再写一句另想过哪种、为什么没选。
- 汇报片里能用 PowerPoint 原生图表画出来的，用可编辑的原生图表；形式照这张表选。
- 下表前 14 行是讲“差多少、由什么构成、怎么算出来”的形式，先在这里找；找不到合适的再往下看。

## 一、对照表

| 想说什么 | 用什么图 | 要点 |
|---|---|---|
| 两组走势差多少（分周、分月对标） | 差值条带：上面两条线，下面另起一行带数字的差值柱；要保留原始线时，在两线之间涂出差值面积，或在线尾标数 | 差多少直接画出来或写出来，不让读者自己比两条线；要看的几期用虚线框住 |
| 一个指标是怎么算出来的 | 一行带真实数字的算式；每一项还要看变化时，改成算式图（每项一张小图，图之间用大号“＋”“×”连起来） | 每项上面写名字、下面一行灰字写口径；结果用强调色 |
| 算法、计算规则、判定步骤 | 步骤图示 | 不超过 4 步，一个真实例子贯穿到底；用成比例的条和大数字，不套方框 |
| 一个差距由哪几块组成 | 差距拆解堆叠条 | 段内写数，右边写合计 |
| 几项加起来等于合计（一本账的构成） | 瀑布图：首项深色、中间浅灰、合计用强调色 | 每根柱上一个大数字；只画能累加的分解 |
| 几项措施各值多少、合计多少 | 编号清单加数值标签 | 合计用强调色；条目不超过 6 条 |
| 分几步推进，每步累计到多少 | 累计台阶 | 台阶之间标增量 |
| 一层层筛下来还剩多少 | 层层收缩的横条 | 每条写数量和占上一层的比例，最后一条用强调色 |
| 承诺的范围和实际落点 | 时间窗条加实际点 | 窗画成浅条，实际画成点并标数 |
| 时间序列里分了几个阶段 | 阶段底色加图例条（加在已有的时间图上） | 底色极浅，图下一行阶段说明 |
| 哪几期超过了上限 | 超过上限的柱变色 | 写明是什么上限 |
| 同一组对象要同时看两个指标 | 柱高表示一个指标，柱顶文字写另一个 | 不用双轴 |
| 三个并列的部分各占多少 | 三栏文字加底部大数字 | 每栏两三行短话，最要紧的一栏圈出来 |
| 几个场景、两三个指标，改前改后各是多少（放在开头当总览） | 前后对比总览表 | 每个指标两列：“前 → 后”和加粗的“变化”；合计行排在最下、上面加细线；不适用的格子写“—” |
| 谁高谁低、排名 | 横向条形图；项目超过 12 个用点图 | 按值排序；重点对象深色，其余灰 |
| 随时间怎么变 | 期数少用柱，期数多用线 | 时间一律放横轴；相邻几张线图刻度一致 |
| 各部分占总量多少 | 100% 堆叠条，或很简单的饼图 | 不超过 5 段，“其他”放最后用灰；只关心比例用 100%，比例和总量都要看用普通堆叠 |
| 从 A 走到 B 由哪些部分构成 | 瀑布图 | 互斥的情景用横条，不用瀑布；柱子不超过 10 根 |
| 前后对比、重点是“变了多少” | 配对柱加差值标注；项目多时用表格加差值数据条 | 差值标注用深灰底白字，不用绿红 |
| 起点不同的几条线，比增速 | 指数化折线（基期 = 1.0） | 基期写进副标题 |
| 实际、应有、上限放一起 | 双柱加一段红色上限线 | 判定文字放柱下 |
| 实际是否落在正常范围 | 灰色正常带加实际线 | 写明灰带是什么范围（历史 80% 的读数、±2 倍标准差）；给出完整历史，别把正常波动画成危机 |
| 某件事之后趋势变了没有 | 折线加竖虚线标事件 | 竖线必须带文字（“W6 月付涨价”）；虚线＝参考或预测，实线＝实际 |
| 很多条线缠在一起 | 小多图（每个对象一个小面板） | 所有面板同轴同刻度 |
| 排名怎么变 | 斜率图（两三个时点）；超过 15 项用排名表加变化列 | 不用 bump chart |
| 矩阵里的高低模式 | 单色热力图 | 行列按值排序；看出结论后改成更直接的图 |
| 很多类别 × 一个指标 | 表格加数据条（渲染成图） | 隔行浅灰；有正负时用零点竖线 |
| 实际、计划、预测同图 | 实心 / 空心描边 / 斜纹区分 | 单色体系下用纹理区分，不加颜色 |

## 二、叙事手法

1. **图是一句话**：标题单独拿出来也能懂；“趋势”“现状”这类标题算失败。
2. **只用一处强调**：灰底上一处高亮指向结论；不要粗体、颜色、大小三种强调一起上。
3. **只放打磨过的一两张主图**：探索时画的全量图不进汇报。
4. **标注分两种**：说“是什么”的、说“为什么”的；一张图一两个就够。
5. **差值替读者算好**：两条线之间用括号写差值，两根柱之间用差值标注。
6. **“什么是正常”画成灰带**：本期落在带里，就说“在日常波动范围内”，这是讲“没有变化”最诚实的画法。
7. **预测带不确定性**：中值实线加灰色区间；区间的数写在正文。
8. **诚实地画“没测出变化”**：画处理组减对照组的差值点和区间，以 0 为参考线；区间跨过 0＝分辨不出。同时给幅度和区间，不只说“显著 / 不显著”。
9. **前后对比先看前期是否平行**：对照组和处理组同轴两条线，前期平行，后期的差才有意义。
10. **刻度诚实**：柱图从 0 起；线图可以不从 0 起，但相邻几张图的范围一致，不压缩刻度把小波动画成剧变。

## 三、图上的标注手法

图画完再问一句：读者第一眼该看哪里、该记住哪个数？用下面的手法点出来。一张图最多用两种，圈点最多两处。

| 手法 | 什么时候用 | 画法 |
|---|---|---|
| 圈点加引线说明 | 一堆数里只有一两个要看 | 细线椭圆圈住那个数，引线拉到一句短话 |
| 图下结论带 | 图说完了，要落到一句带数的话 | 通栏一句，上下各一条细线 |
| 均值线加差值标签 | 主角比其他对象的平均高或低多少 | 均值画虚线并写数，主角单独上色，旁边标“+45%” |
| 说明挂在柱上 | 某一根柱为什么是这个数，要交代一句 | 两三行小字，细线连到那根柱 |
| 右侧增速列 | 堆叠柱各段各涨了多少 | 图右单设一列，和各段对齐 |
| 线尾标签 | 两条线各自的增速 | 线尾各挂一个“每年约 4%” |
| 轴下附加数字行 | 每一期还对应另一个量 | 类目轴下面再加一行数 |
| 趋势箭头加增速标签 | 一串柱整体涨了多快 | 首尾柱顶之间一条细箭头，中间一个标签 |
| 弧形箭头加标签 | 两根柱之间是几倍 | 标签写成“是它的 1.9 倍”；差多少照旧用深灰的差值标注 |

## 四、不用的图

| 不用 | 原因 | 改用 |
|---|---|---|
| 哑铃图、箭头图（同一行上两个点、中间连一条线）。斜率图不在此列 | 读者要自己估两点间的距离，差值反而看不清 | 配对柱加差值标注；项目多时用表格加差值数据条 |
| 带色块表头的方框流程图，或四五个方框排一行再配一堆小字 | 不形象，字多，读者看不出每一步算了什么 | 步骤图示、一行带数字的算式 |
| 两条折线并排画、让读者自己比（只指分周、分月对标；指数化折线、小多图照旧） | 差多少要读者自己算 | 差值条带、两线之间的差值面积 |
| 水桶、水池这类比喻式的流量图 | 比喻占地方，数却看不清 | 存量和流入流出用一行数字链或瀑布图 |
| 用一排排圆点或小人代表人数、单量的示意图 | 占的位置大，表达的信息少 | 步骤图示；数字本身放进总览表或柱图 |
